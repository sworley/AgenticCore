# Release v0.7.0

**Date:** 2026-11-09
**Tag:** `v0.7.0`
**Branch:** `release/v0.7.0`
**Previous release:** v0.6.0

## Summary

v0.7.0 completes the post-v0.6.0 hardening. It finishes migrating the framework's
namespace code from the old `AP` slug to **`AC`** (AgenticCore) across docs, bench
tooling, and ADRs — so the harness is internally consistent — and refreshes the MCP
dependency set. No adopter-facing interface changes; a maintenance/consistency release.

## What Changed

### New Capabilities

None. This is a maintenance/consistency release — no new adopter-facing capability.

### Improvements

- **`AP` → `AC` namespace migration (framework consistency)**
  - Docs/runbooks placeholders (`AP-NNN` → `AC-NNNN`)
  - Bench tooling (`provision-bench.sh`, `bench-status.sh`, bench templates,
    substitution test, severance-test marker)
  - ADRs (`AC ADR-NNNN`) and reference docs (`adopter-reconciliation`,
    `shared-context`, PROCESS POC refs)
- **Release-process hardening**
  - `release-process.md` — repository-specific mechanics + operational notes
  - `AC-0004`..`AC-0006` tracking

### Infrastructure / Dependencies

- **Dependency refresh** (verified import-compatible):
  - `mcp` 1.28.1 → 1.30.0
  - `fastmcp` 3.4.2 → 3.4.10
  - `fastmcp-slim` 3.4.2 → 3.4.10
- `AC-0007`..`AC-0009` tracking
