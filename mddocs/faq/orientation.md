# FAQ: How Do I Quickly Get Oriented?

**Question (2026-11-02 session):** "Is this represented in an easy way for anyone
wanting to try this harness as an open-source product? Do we have that level of
documentation?"

## Answer

Yes. Start with the [Visual Overview](../onboarding/visual-overview.md) — a
single-page map of the bench hierarchy, personas, workflows, and agent roster. From
there:

1. [Getting Started](../onboarding/getting-started.md) routes you to **adopter** vs.
   **contributor**.
2. The project **[README](../../README.md)** covers the adopter Quick Start
   (`adopt.sh`/`export-framework.sh`) and the maintainer workflow.
3. The mdBook docs in `mddocs/` are the full reference: ADRs, runbooks, onboarding.

The repository is documentation-first, so each concept also has a canonical source
doc — the FAQ answers link back to those rather than restating them.
